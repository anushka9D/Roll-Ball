**Roll Ball** is an offline single-player mobile game built using the Unity Game Engine. Designed for Android and iOS, the player controls a constantly forward-moving ball, guiding it left and right to avoid obstacles, stay on the path, and collect coins.

![Roll Ball Screenshot](https://github.com/anushka9D/Anushka_Dilshan/blob/main/img/project/mobile-game1.png)

---

## 🧠 Game Description

In **Roll Ball**, the objective is simple yet challenging:

- The ball moves forward automatically.
- You can control the ball's direction (left and right) to avoid hitting obstacles.
- If the ball falls off the path or hits an object, the level restarts.
- Collect coins along the way to increase your score.
- Progress through levels and save your game state.
- Your current score is always displayed at the top of the screen.

Stay on track, avoid dangers, and collect as many coins as you can!

## 🕹️ How to Play

1. When the game starts, the ball begins moving forward automatically.
2. Use touch/swipe controls (or keyboard if testing in Unity editor) to move the ball left or right.
3. Avoid all obstacles and stay within the playable platform boundaries.
4. Hit coins to collect them and increase your score.
5. If you fall or hit an obstacle, the level restarts.
6. Save your progress and continue through new levels.

## 🚀 Installation

To run the game locally or build an APK:

```bash
# 1. Clone the repository

# 2. Open the project in Unity (preferably the same version used for development)

# 3. Run the game in editor OR build the APK:
#    File > Build Settings > Android > Build

# 4. Transfer the APK to your phone and install it
```
